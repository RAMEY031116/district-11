# District 11 home-screen app

Enable GitHub Pages in repository Settings → Pages → Deploy from a branch → main → /docs → Save.

After the deployment completes, open https://ramey031116.github.io/district-11/ on the phone. Add THIS address to the home screen (not district11.streamlit.app). Remove an old Streamlit shortcut before installing again. On iPhone, use Safari → Share → Add to Home Screen → Open as Web App. On Android, use Chrome → Install app / Add to Home screen.

The launcher embeds the existing public Streamlit application with its supported embed parameter. Supabase data and the Streamlit deployment are unchanged. This is an online app; only the launcher and icon files are cached. A private Streamlit app may not embed successfully.

Validation: icon dimensions and manifest asset paths checked locally. Physical iPhone/Android installation remains to be verified after Pages is enabled.
